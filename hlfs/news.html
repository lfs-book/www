HLFS 0.2 Released
Archaic - 2005/01/17

HLFS has just released version 0.2. This release contains the just-released uClibc-0.9.27 as well as an updated snapshot of iproute2-2.6.10. There are also many textual corrections.

The book can be downloaded from downloads/alpha/hlfs-0.2.tar.bz2, or if you prefer to grab it straight from svn:

svn export svn://svn.linuxfromscratch.org/HLFS/tags/release-0.2 hlfs-0.2

HLFS 0.2-pre1 Released
Archaic - 2005/01/10

HLFS has just released its second alpha version. It is being released as a pre-release because no changes other than bugfixes will occur prior to the 0.2 release. The 0.2 release is being earmarked for the point at which the toolchain will be pretty much complete. Further releases will be geared towards building a system on top of this toolchain.

Major changes from 0.1 to 0.2-pre1:

  • Two C libraries are present. Glibc and uClibc.
  • The bugs with shared linking in 0.1 are gone.
  • Took the native pass2 builds of binutils and gcc out.
  • Removed pie and sspspecs patches, using Perl commands instead.
  • Now libraries are getting stack protection, before it was only executables.

Many more changes are in the changelog in chapter01.

The book can be downloaded from downloads/alpha/hlfs-0.2-pre1.tar.bz2, or if you prefer to grab it straight from svn:

svn export svn://svn.linuxfromscratch.org/HLFS/tags/release-0.2-pre1
