  • Read the security advisories page.

Miscellaneous Errata

  • In the installation of Systemd, the tarball systemd-man-pages-250.tar.xz was untarred with --strip-components=1, causing the man pages installed into the wrong location. You should remove this --strip-components=1 option building Systemd when you are following the LFS 11.1-systemd book. If you have already built LFS 11.1-systemd, remove the misplaced man pages by running the command as the root user: rm -v /usr/share/man/*.[0-9]. If you have not reinstalled Systemd following BLFS instruction with the optional packages for rebuilding the manual pages, and does not plan to do so, you can reinstall the man pages by running tar xf systemd-man-pages.250.tar.xz -C /usr/share/man as the root user.
  • A bug of GCC 5.1 can cause GCC Pass 1 fail to build, so in the host system requirements the minimal GCC version should be 5.2, instead of 5.1.
