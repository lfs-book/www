Errata for the 6.1 Version of the LFS Book

Below is a list of known security vulnerabilites and other bugfixes that are serious enough to warrant a change in how the affected package is compiled and installed.

  • A security vulnerability exists in zlib-1.2.2 whereby disrupted streams can cause a buffer overflow. Zlib-1.2.3 fixes this issue. Users are strongly recommended to upgrade to Zlib-1.2.3.
