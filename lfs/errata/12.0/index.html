Errata for the 12.0 Version of the LFS Book

Known Security Vulnerabilities

  • Read the security advisories page.

Miscellaneous Errata

  • A bug of GCC 5.1 can cause GCC Pass 1 fail to build, so in the host system requirements the minimal GCC version should be 5.2, instead of 5.1.
  • If a package manager is used, in udev (from systemd-254) the rules.d/70-uaccess.rules, rules.d/71-seat.rules, rules.d/73-seat-late.rules, and ../rules.d/70-power-switch.rules files should be removed before "Install the package" to avoid a conflict with BLFS elogind package.
  • Due to an oversight extracting udevd from systemd, the udevd in LFS 12.0 does not name network devices with physical characteristics. This contradicts with the text description in section 9.4.1. If you needs the NIC naming based on physical characteristics, create the /usr/lib/systemd/network directory and copy the systemd-254/network/99-default.link file (extracted from systemd-254.tar.gz) to /usr/lib/systemd/network/99-default.link.
