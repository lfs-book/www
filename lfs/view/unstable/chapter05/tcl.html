5.9. Tcl-8.4.9

Approximate build time: 0.9 SBU
Required disk space: 23 MB

5.9.1. Installation of Tcl

Prepare Tcl for compilation: 

cd unix
./configure --prefix=/tools

Build the package: 

make

To test the results, issue: TZ=UTC make test.

Install the package: 

make install

Warning

Do not remove the tcl8.4.9 source directory yet, as the next package will need its internal headers.

Now make a necessary symbolic link: 

ln -s tclsh8.4 /tools/bin/tclsh
