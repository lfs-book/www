5.26. Tar-1.15.1

Approximate build time: 0.2 SBU
Required disk space: 10 MB

5.26.1. Installation of Tar

Prepare Tar for compilation: 

./configure --prefix=/tools

Compile the package: 

make

To test the results, issue: make check

Install the package: 

make install
