5.16. Bzip2-1.0.2

Approximate build time: 0.1 SBU
Required disk space: 2.5 MB

5.16.1. Installation of Bzip2

The Bzip2 package doesn't contain a configure script. Compile it with a straightforward: 

make

And install it: 

make PREFIX=/tools install
