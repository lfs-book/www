5.8. Adjusting the toolchain

Run the following command from within the binutils-build directory: 

make -C ld install

Amend the GCC specs file: 

SPECFILE=`gcc --print-file specs` &&
sed 's@ /lib/ld-linux.so.2@ /tools/lib/ld-linux.so.2@g' \
    $SPECFILE > tempspecfile &&
mv -f tempspecfile $SPECFILE &&
unset SPECFILE

Make clean-up: 

rm -f /tools/lib/gcc/*/*/include/{pthread.h,bits/sigthread.h}

Test the tools: 

echo 'main(){}' > dummy.c
cc dummy.c
readelf -l a.out | grep ': /tools'

The output of the last command will be of the form: 

[Requesting program interpreter: /tools/lib/ld-linux.so.2]

Remove the test files: 

rm dummy.c a.out
