5.33. Perl-5.8.6

Approximate build time: 0.8 SBU
Required disk space: 74 MB

5.33.1. Installation of Perl

First adapt some hard-wired paths to the C library: 

patch -Np1 -i ../perl-5.8.6-libc-1.patch

Now prepare Perl for compilation: 

./configure.gnu --prefix=/tools -Dstatic_ext='IO Fcntl POSIX'

Compile only the required tools: 

make perl utilities

Then copy these tools and their libraries: 

cp perl pod/pod2man /tools/bin
mkdir -p /tools/lib/perl5/5.8.6
cp -R lib/* /tools/lib/perl5/5.8.6
