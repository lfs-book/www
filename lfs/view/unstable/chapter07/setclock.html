7.4. Configuring the setclock script

Create a new file /etc/sysconfig/clock by running the following: 

cat > /etc/sysconfig/clock << "EOF"
# Begin /etc/sysconfig/clock

UTC=1

# End /etc/sysconfig/clock
EOF
