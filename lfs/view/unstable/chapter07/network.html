7.10. Configuring the network script

7.10.1. Creating network interface configuration files

The following command creates a sample ipv4 file for the eth0 device: 

cd /etc/sysconfig/network-devices &&
mkdir ifconfig.eth0 &&
cat > ifconfig.eth0/ipv4 << "EOF"
ONBOOT=yes
SERVICE=ipv4-static
IP=192.168.1.1
GATEWAY=192.168.1.2
PREFIX=24
BROADCAST=192.168.1.255
EOF

7.10.2. Creating the /etc/resolv.conf file

Create the file by running the following: 

cat > /etc/resolv.conf << "EOF"
# Begin /etc/resolv.conf

domain {[Your Domain Name]}
nameserver [IP address of your nameserver]

# End /etc/resolv.conf
EOF
