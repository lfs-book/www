9.3. Rebooting the system 

logout
umount $LFS/dev/pts
umount $LFS/dev/shm
umount $LFS/dev
umount $LFS/proc
umount $LFS/sys
umount $LFS

If multiple partitions were created, unmount the other partitions before unmounting the main one, like this: 

umount $LFS/usr
umount $LFS/home
umount $LFS
shutdown -r now
