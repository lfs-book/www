6.59. Udev-050

Approximate build time: 0.2 SBU
Required disk space: 5.2 MB

6.59.1. Installation of Udev

Compile Udev: 

make udevdir=/dev

Install it: 

make udevdir=/dev install

Install our configuration files: 

cp ../udev-config-2.permissions /etc/udev/permissions.d/25-lfs.permissions
cp ../udev-config-1.rules /etc/udev/rules.d/25-lfs.rules

Create the full compliment of device nodes: 

/sbin/udevstart
