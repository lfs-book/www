6.24. M4-1.4.2

Approximate build time: 0.1 SBU
Required disk space: 3.0 MB

6.24.1. Installation of M4

Prepare M4 for compilation: 

./configure --prefix=/usr

Compile the package: 

make

To test the results, issue: make check.

And install the package: 

make install
