6.60. Util-linux-2.12p

Approximate build time: 0.2 SBU
Required disk space: 16 MB

6.60.1. FHS compliance notes

Issue a sed sustitution: 

sed -i 's@etc/adjtime@var/lib/hwclock/adjtime@g' hwclock/hwclock.c
mkdir -p /var/lib/hwclock

6.60.2. Installation of Util-linux

Util-linux has a compilation error against newer versions of the linux-libc-headers. The following patch properly fixes that issue 

patch -Np1 -i ../util-linux-2.12p-cramfs-1.patch

Prepare Util-linux for compilation: 

./configure

Compile the package: 

make HAVE_KILL=yes HAVE_SLN=yes

Now install the package: 

make HAVE_KILL=yes HAVE_SLN=yes install
