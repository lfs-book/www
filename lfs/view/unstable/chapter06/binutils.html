6.13. Binutils-2.15.94.0.2

Approximate build time: 1.4 SBU
Required disk space: 167 MB

6.13.1. Installation of Binutils

Check if there is PTYs for the test suites: 

expect -c "spawn ls"

Create the build directory: 

mkdir ../binutils-build
cd ../binutils-build

Now prepare Binutils for compilation: 

../binutils-2.15.94.0.2/configure --prefix=/usr --enable-shared

Compile the package: 

make tooldir=/usr

Test the results: 

make -k check

The test suite notes from Section 5.13, “Binutils-2.15.94.0.2 - Pass 2” are still very much appropriate here..

Install the package: 

make tooldir=/usr install

Install the libiberty header file: 

cp ../binutils-2.15.94.0.2/include/libiberty.h /usr/include
