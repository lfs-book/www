6.32. Iproute2-2.6.9-041019

Approximate build time: 0.1 SBU
Required disk space: .6 MB

6.32.1. Installation of iproute2

Apply a patch 

patch -Np1 -i ../iproute2-2.6.9_041019-remove_db-1.patch

The patch below fixes the issue with the newer versions of findutils, the issue will give an error message it options are not in the proper order. This patch corrects this issue for IPRoute2. 

patch -Np1 -i ../iproute2-2.6.9_041019-find_update-1.patch

Prepare iproute2 for compilation: 

./configure

Compile the package: 

make SBINDIR=/sbin

Now install it: 

make install SBINDIR=/sbin
