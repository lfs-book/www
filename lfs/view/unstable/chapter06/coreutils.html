6.15. Coreutils-5.2.1

Approximate build time: 0.9 SBU
Required disk space: 69 MB

6.15.1. Installation of Coreutils

Apply a patch: 

patch -Np1 -i ../coreutils-5.2.1-uname-2.patch

Apply another patch: 

patch -Np1 -i ../coreutils-5.2.1-suppress_uptime_kill_su-1.patch

Now prepare Coreutils for compilation: 

DEFAULT_POSIX2_VERSION=199209 ./configure --prefix=/usr

Compile the package: 

make

Create two dummy groups and a dummy user name: 

echo "dummy1:x:1000:" >> /etc/group
echo "dummy2:x:1001:dummy" >> /etc/group
echo "dummy:x:1000:1000:::/bin/bash" >> /etc/passwd

Run the root tests: 

make NON_ROOT_USERNAME=dummy check-root

Run the user tests: 

src/su dummy -c "make RUN_EXPENSIVE_TESTS=yes check"

Remove the dummy user and groups: 

sed -i '/dummy/d' /etc/passwd /etc/group

Install the package: 

make install

And move some programs to their proper locations: 

mv /usr/bin/{[,basename,cat,chgrp,chmod,chown,cp,dd,df} /bin
mv /usr/bin/{date,echo,false,head,install,ln,ls} /bin
mv /usr/bin/{mkdir,mknod,mv,pwd,rm,rmdir,sync} /bin
mv /usr/bin/{sleep,stty,test,touch,true,uname} /bin
mv /usr/bin/hostname /bin
mv /usr/bin/chroot /usr/sbin

Create a symlink: 

ln -s ../../bin/install /usr/bin
