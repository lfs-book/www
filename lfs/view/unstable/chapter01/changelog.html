1.2. Changelog

This is version SVN-20050109 of the Linux From Scratch book, dated January 9, 2005. If this book is more than two months old, a newer and better version is probably already available. To find out, please check one of the mirrors via http://www.linuxfromscratch.org/.

Below is a list of differences between the Testing and Unstable versions of the LFS Book.

  • Upgraded to:

    • findutils-4.2.11

    • glibc-20041220

    • lfs-bootscripts-3.1.0

    • linux-libc-headers-2.6.10.0

  • Added:

    • bash-3.0-fixes-3.patch

    • iproute2-2.6.9_041019-find_update-1.patch

  • Removed:

    • bash-3.0-fixes-1.patch

  • January 9th, 2005 [jeremy]: Removed --enable-shared from libol, since the shared library is installed by default for this package - thanks Archaic

  • January 5th, 2005 [jeremy]: Upgraded to findutils 4.2.11

  • December 31st, 2004 [jeremy]: Oops - forgot to remove the separate targets for hotplug and syslog-ng - fixed.

  • December 31st, 2004 [jeremy]: Upgrade to LFS-Bootscripts 3.1.0

  • December 30th, 2004 [jeremy]: Added Archaic's sed to stop installation of shadow's groups binary, as well as it's man page.

  • December 25th, 2004 [jeremy]: Upgrade to glibc snapshot of 20041220

  • December 19th, 2004 [jeremy]: Updated GCC-testresults link to be appropriate for GCC 3.4.3

  • December 6th, 2004 [jim]: Fixes a few typo's done by me. Added a patch for IPRoute2 to fix usage with the newer findutils. Updated Readline and Zlib library location changes. Bumped findutils to 4.2.9 and util-linux 2.12j. Used the same methodology used on zlib and readline on shadow.

  • December 3rd, 2004 [jim]: Changed readline and zlib instructions to use --libdir for the libraries. Bumped perl to 5.8.6. Corrected wording in readline.
