6.55. Libol-0.3.14

The Libol package contains support libraries needed by Syslog-ng.

Approximate build time: Unchecked
Required disk space: Unchecked

6.55.1. Installation of Libol

Prepare Libol for compilation 

./configure --prefix=/usr --enable-shared

Compile the package: 

make

Install the package: 

make install
