Roadmap for the Official LFS LiveCD

Currently, the biggest focus of the livecd project is documentation of the cd build and creation of scripts to automate the build. The documentation is expected to follow during the natural course of the script development. Below is a TODO list for the script development.

  • Check that chroot system mounts are being done correctly (proc, sys, etc.)
  • Finish up the chroot build section for the lfs-base
  • Extend the base system to include BLFS packages
  • Add a section for building a cdrtools and squashfs (outside the cd system)
  • Add custom bootscript package to svn repo
  • Setup kernel build -- include initramfs build
  • squash up /usr
  • Build the iso

In the future, we hope to be able to create other specific versions of the LiveCD. Already some work has been done on a ppc version. There also have been requests for a HLFS based cd and an x86_64 version.
