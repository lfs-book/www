Support for the LFS LiveCD

The LFS LiveCD project offers support in a number of ways. However, we ask that you make use of them in the following order and according to the guidelines for each method.

FAQ

The list of Frequently Asked Questions can be found here: FAQ. Quite often, problems you encounter in using the LiveCD have already been discovered and a solution found and documented. Checking here first saves you time and grievance as often developers are not keen on repeatedly answering questions that have already been answered.

Search the Mailing Lists

If you haven't found your particular problem listed in the FAQ, try searching the mailing lists, as the problem may have only recently been found, or is rare enough to not warrant a FAQ entry. You can use the search form and button on any web page within the site, or for more advanced searching, visit the search pagedirectly.

IRC

If you have tried both of the above and still have not found a solution, feel free to pop into one of our IRC channels located at irc.linuxfromscratch.org. #lfs-support is the channel set up specifically for support . #lfs is reserved for more general conversation.

Mailing Lists

Finally, there are mailing lists available to offer support. The livecd listis the main mailing list reserved for support. You can also view all the lists.
