LiveCD Version x86-6.1-1-pre4 Released
Justin Knierim - 2005/07/09

The LiveCD Team is proud to announce the release of the 6.1-pre4 LFS LiveCD. This release includes some new features such as video card autodection, terminal auto-login and dialogs that at boot allow you to select timezone, keyboard layout, and locale. The release includes the package versions now as in the 6.1 book, including a patch to fix the recent zlib library vulnerabilty.

Please see the download page for the LiveCD mirror nearest you. Thanks, and have fun!

LiveCD Version x86-6.1-1-pre3 Released
Jeremy Huntwork - 2005/05/22

There is a new LiveCD available, version x86-6.1-1-pre3. There are still a few known missing items that we will put in the next iso, and hopefully that one will be a release candidate. However, there are some substantially new features with this cd, so we wanted to give the community an opportunity to test it out before we release.

Please see the download page for the LiveCD mirror nearest you. Thanks, and have fun!
