LiveCD Version x86-6.2-pre2 Released
Jeremy Huntwork - 2005/12/21

The LFS LiveCD team is proud to announce a new pre-release version of the LiveCD. Since this version of the LiveCD is tracking the LFS development instructions and is slated for release when the current LFS development book becomes stable, there will likely be many changes between this CD and the final x86-6.2 CD. We are pre-releasing at this time so that we can receive feedback on the new features we have included. Most notable among new features is the support for UTF-8 locales, and a modified version of the LFS Book for use in building a UTF-8 capable LFS system.

The CD, lfslivecd-x86-6.2-pre2.iso, is available for download on all mirrors. To download, please visit the download page.

Please send any comments or suggestions to the LiveCD Mailing List.

LiveCD Version x86-6.1.1-2 Released
Justin Knierim - 2005/12/11

The LFS LiveCD team is proud to announce the release of the x86-6.1.1-2 version of the LFS LiveCD. This version is built using LFS 6.1.1 and BLFS packages from the svn branch. This version also fixes bugs found in the previous LiveCD, 6.1.1-1. Changes include:

  • nALFS-profile upgraded to 6.1.1-1.
  • Package tarballs for libxml2 and nALFS included in /lfs-sources (nALFS optional dependency).
  • Corrected versions of iana-etc and man-pages included in /lfs-sources.
  • Fixed other timezone related issues.

Please mail any comments to the LFS LiveCD mailing list: LiveCD Mailing List. Thank you.

To download the new LiveCD, visit the LFS LiveCD download page for a list of mirrors.

LiveCD Version ppc-6.2-pre1 Released
Jeremy Huntwork - 2005/11/30

A new ppc LiveCD has been released! Due to the limited number of machines at our disposal, development of the ppc LiveCD moves a little slower than the x86 versions. However, we have merged the once separate x86 and ppc build scripts into one, allowing general development of the ppc CD to move more quickly. This new version of the ppc LiveCD is the first released result of this merge for PowerPC.

This CD is geared specifically toward new-world Macs. If you have one and would like to test this pre-release CD, we would appreciate your assistance in spotting any bugs or missing features. Please mail any comments to the LFS LiveCD mailing list: LiveCD mailing list. Thank you.

To download the new LiveCD, visit the LFS LiveCD download page for a list of mirrors.
