LiveCD Version x86-6.1-1 Released
Jeremy Huntwork - 2005/07/11

The LFS LiveCD Team is proud to announce the release of version x86-6.1-1 of the LiveCD.

We have changed to a new versioning scheme as follows:

The first field identifies the architecture of the CD (x86), the second field is the version of LFS Book the CD targets and is built upon (6.1), and the final field is an incremental number pinpointing the actual release number (1). During a pre-release cycle, the final field will be versioned with pre1, pre2, etc.

There are many new features available in this CD when compared to the 6.0 version, such as:

  • Unionfs (allowing for the entire contents of the CD to be writable)
  • Unattended network configuration for sshd
  • Vast improvement in internationlization (i18n)
  • Ion and Xfce replacing Fluxbox
  • Video card auto-detection
  • Raidtools
  • LVM
  • Distcc
  • Many other general enhancements

To download the new LiveCD, visit the LFS LiveCD download page for a list of mirrors.
