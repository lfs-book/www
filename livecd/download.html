LiveCD Repository

The LFS LiveCD project has a subversion repository. At present, this contains cd documentation, specific configuration files for the cd and build scripts that are under development. Eventually the scripts will allow you to automate the entire process of building an official cd from scratch.

You can view the repository via viewcvs: LiveCD Repository

Or, if you have subversion, check out the repository locally:

svn co svn://svn.linuxfromscratch.org/livecd/trunk > lfs-livecd
