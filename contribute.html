How to Contribute

Become a mirror

You can assist the LFS project by providing a mirror for HTTP and/or FTP. HTTP consists of the XHTML, books, patches and hints, while FTP consists of packages, patches and tarballs thereof.

HTTP Mirror

Here is a checklist of requirements for HTTP mirrors:

  • Rsync for syncing with the LFS server.
  • A cron-like program to sync twice an hour.
  • At least 125MB of disk space.
  • Apache Webserver or equivalent with the following options enabled:
    • Indexes
    • FollowSymlinks
    • IncludesNOEXEC
    • AllowOverride FileInfo
    • +Includes
    • XBitHack on
    • The mod_rewrite.so module loaded

FTP Mirror

Here is a checklist of requirements for FTP mirrors:

  • Rsync for syncing with the LFS FTP server.
  • A cron-like program to sync twice a day.
  • At least 1.5GB of disk space.
  • The path to the mirror being "/pub/lfs", if possible.

Rsync Scripts

For HTTP mirrors, please download the lfs-rsync.sh script and change the HTMLDIR variable to where you store your LFS website. Schedule this script to run twice an hour at a randomly chosen time.

For FTP mirrors, please download the lfs-ftp-rsync.sh script. Next please ask for an hour to sync from the FTP Mirror Maintainer (e-mail below) and schedule this script to run twice a day at the scheduled times.

Still interested?

For HTTP mirrors, once you have the server available, please email the server-admin list with the following information:

  • Location (City and Country)
  • Hostname and/or IP Address
  • Bandwidth

For FTP mirrors, please e-mail the FTP Mirror Maintainer Justin Knierim or Tim Jackson to receive an rsync time. Please include the following information as well:

  • Location (City and Country)
  • Hostname and/or IP Address
  • Bandwidth
  • Contact Name and E-mail Address

Make a donation

One of the ways to help the Linux From Scratch project is by making donations. Financial donations can be made through PayPal using a major credit card.

USD $

If you want to donate but can't use PayPal, please contact Gerard Beekmans.

The majority of donations will be used to pay the monthly server colocation bill. Anything left over will be put back into the project such as sending people cdroms who don't have a high-speed Internet connection to download all the required packages, upgrade the server hardware when necessary, or whatever else needs done to keep the LFS project running smoothly.
