Support for Patches

The Patches project offers support in a number of ways. However, we ask that you make use of them in the following order and according to the guidelines for each method.

FAQ

The list of Frequently Asked Questions can be found here: FAQ Quite often, problems you encounter in building LFS or BLFS have already been discovered and a solution found and documented. Checking here first saves you time and grievance as often developers are not keen on repeatedly answering questions that have already been answered.

Search the Mailing Lists

If you haven't found your particular problem listed in the FAQ, try searching the mailing lists. The Patches project does not have a support list, so any questions should be asked on the mailing list for the project you are building, such as lfs-support or blfs-support. You can use the search form and button on any web page within the site, or for more advanced searching, visit the search page directly.

IRC

If you have tried both of the above and still have not found a solution, feel free to pop into one of our IRC channels located at irc.linuxfromscratch.org. #lfs-support is the channel set up specifically for support . #lfs is reserved for more general conversation.

Mailing Lists

Finally, there are mailing lists available to offer support. The lfs-support list is the main mailing list for LFS support, and blfs-support list is the main mailing list for BLFS support. You can also view all the lists.
