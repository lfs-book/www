Errata for BLFS systemd Version 12.1

  • In asymptote the optional dependency on dvisvgm was not shown because it no longer worked and it was unclear if it was still supported (the documentation is hard to follow unless you have used asymptote in a class). Eventually it became clear that the problem was a change in ghostscript-10.02.1. Creation of svg files from asymptote now works with asymptote-2.88, dvisvgm-3.2.2 and ghostscript-10.03.0 on those machines where the GPU is able to produce 3D output from asymptote, although in rare case it might need the maxtile command-line option to be used to specify a size less than the monitor, e.g. -'maxtile 1023,768'.
  • At the end of March 2024, Mozilla sunset the Mozilla Location Service. Firefox and Geoclue both need to be adapted to handle this. For Firefox, rebuild it with the Mozilla API Key removed, and ensure the Google API Key is set (if geolocation services were enabled). For Geoclue, follow the instructions in the book to configure it to use the Google Geolocation Service.
  • In Tuning Fontconfig, the information that KDE Plasma saves font settings in ~/.config/fontconfig/fonts.conf seems incorrect and wrongly claimed that the same file, if installed, could override that. Obviously a typo, but it appears that neither that file nor /etc/fonts/local.conf have any effect on applications from either KDE5 or KDE6. Fonts can be specified in the application's preferences (e.g. Falkon, Konsole) as an alternative to using Plasma System Settings.
  • In xfce4-power-manager, polkit should be recommended for laptop backlight control at build time, not only runtime.
