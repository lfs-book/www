Errata for BLFS systemd Version 12.4

  • The version of libinput shipped with BLFS 12.4 is known to cause crashes on systems with ALPS touchpads, and 32-bit systems. Please update to libinput-1.29.1 or later to resolve the problem.
  • In the Python Modules page, Pygments should be a required dependency of pytest-8.4.1, instead of an optional dependency.
  • In the dvd+rw-tools page, the patch is malformed. Please use dvd+rw-tools-7.1-consolidated_fixes-2.patch instead.
  • In the Test::Fatal-0.017 page, the md5sum is incorrect. It should be 2f160c31e1848536e3b82112d573bb76.
  • Due to a breaking API change in graphviz-13, valadoc may crash in some circumstances. The patch vala-0.56.18-graphviz_13_fix-1.patch fixes the issue.
  • Due to problems with the systemd units for Kea, attempting to start the daemons will result in errors. Please install the systemd units for Kea from the blfs-systemd-units-20251204 tarball instead.
