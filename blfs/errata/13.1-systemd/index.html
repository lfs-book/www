Errata for BLFS systemd Version 13.1

  • Some demonstrations of kernel configuration are outdated for the Linux kernel version (7.1.8) shipped by LFS 13.1:
    • In the ntfs-3g page, [NTFS_FS] is now a distinct NTFS file system driver, but BLFS 13.1 incorrectly described it as an alias of [NTFS3_FS]. Despite that, we still recommend to enabling both as modules for coverage.
    • [IPV6] is now impossible to be built as a module. Fortunately BLFS has been always demonstrating to enable it as a part of the main kernel image instead of a module for a long time, but it should now be demonstrated as [*], instead of <*> in BLFS 13.1.
    • Various items in the Graphics support section (demonstrated in the Mesa and Xorg Server pages) are ordered differently in Linux 7.1.8 configuration interface from the BLFS 13.1 book.
