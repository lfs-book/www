Errata for BLFS Version 7.5

  • There are several references throughout the book to $QTDIR. This reference should be $QT4DIR. Packages that are affected include Grantlee, Libdbusmenu-qt, Qca, Qjson, Polkit-Qt, Automoc4, Phonon, and Akonadi. The reference at the end of the page 'Starting KDE' should also be $QT4DIR.
