Errata for BLFS systemd Version 11.0

  • When compiling Shadow in BLFS, changes were made to Makefile.in prior to running 'autoreconf -fiv', which causes those changes to be lost. Run 'autoreconf -fiv' before the changes to Makefile.in instead, and execute the two seds below the one for login.defs first.
  • After release, the repository of SoundTouch-2.3.0 is moved and the download URL in the book is no longer accessible. We recommends to use the latest 2.3.1 release available at https://www.surina.net/soundtouch/soundtouch-2.3.1.tar.gz, which is API and ABI compatible with 2.3.0.
  • The details of running the test suite for shared-mime-info-2.1 are incorrect, the test suite needs to be separately downloaded and compiled in the shared-mime-info directory. For details see the development book.
