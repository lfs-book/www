Errata for BLFS Version 12.1

  • In asymptote the optional dependency on dvisvgm was not shown because it no longer worked and it was unclear if it was still supported (the documentation is hard to follow unless you have used asymptote in a class). Eventually it became clear that the problem was a change in ghostscript-10.02.1. Creation of svg files from asymptote now works with asymptote-2.88, dvisvgm-3.2.2 and ghostscript-10.03.0 on those machines where the GPU is able to produce 3D output from asymptote, although in rare case it might need the maxtile command-line option to be used to specify a size less than the monitor, e.g. -'maxtile 1023,768'.
