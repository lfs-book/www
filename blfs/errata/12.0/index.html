Errata for BLFS Version 12.0

  • In libnotify, if xmlto is not installed and the API documentation is not built via gi-docgen, then no documentation will be installed and the mv command for renaming the documentation directory should be ignored.
  • libxcb can fail to build with certain locale settings. If it happens, use LC_ALL=en_US.UTF-8 make instead of the make command to work around.
  • In webkitgtk, libseccomp should be a recommended dependency because it's required for bubblewrap sandbox.
  • In make-ca, the initial download of the CA certificates could not be done anymore because make-ca-1.12 contains an obsolete certificate. Use make-ca-1.13, which provides the new certificate.
