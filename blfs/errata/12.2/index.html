Errata for BLFS Version 12.2

  • In sysmon-qt, remove cd src from the instructions.
  • In pulseaudio, -D bluez=disable should be -D bluez=disabled, i.e. missing a d.
  • In kirigami-addons, CMAKE__INSTALL_PREFIX should be CMAKE_INSTALL_PREFIX (remove douple underscore character).
  • In x265, the -D GIT_ARCHETYPE=1 switch needs to be passed to CMake in order to generate the shared library and pkg-config file if Git is not installed.
  • In okular, the -D CMAKE_INSTALL_PREFIX option should read $KF6_PREFIX.
  • In Subversion, SWIG is required because we are regenerating the build system to get new versions of the bindings.
  • In xfce4-power-manager, polkit should be recommended for laptop backlight control at build time, not only runtime.
  • The iso-codes-4.16.0 tarball has been removed from Debian pool because it's not included in any Debian stable release. Use the Git snapshot (with md5sum 841cfc1afcb91e50dc03956ca0a2ad37) instead.
