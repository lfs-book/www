Errata for BLFS systemd Version 8.4

  • After release, a problem was discovered with LXDE/LXPanel where right clicking on the taskbar to close a program would sometimes cause LXPanel to crash with a General Protection Fault. To fix this, upgrade to the latest version: http://www.linuxfromscratch.org/blfs/view/systemd/lxde/lxpanel.html.
  • After release, a security problem regarding the mprotect() syscall defined in libseccomp was discovered. Upstream released a new version to solve this problem. The BLFS team recommends upgrading to the latest version: http://www.linuxfromscratch.org/blfs/view/systemd/general/libseccomp.html.

Known Security Vulnerabilities

A few packages are good at reporting that a new release fixes a vulnerability. For some others, such as firefox, virtually every new release includes security fixes. But in many cases the fixes are not documented as security issues.

Updates to the packages in the book may be available in the development version of the book.
