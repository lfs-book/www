Errata for BLFS systemd Version 13.0

  • The instructions for installing GRUB for EFI on a system that doesn't already have GRUB installed are incorrect. The command for moving the bash completions is no longer necessary.
  • The example configuration for GRUB uses the wrong kernel version. Please replace "6.16.1-lfs-12.4" with "6.18.10-lfs-13.0-systemd".
