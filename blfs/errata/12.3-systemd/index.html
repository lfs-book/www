Errata for BLFS systemd Version 12.2

  • In LLVM-19.1.7, if compiler-rt is built, many (more than a hundred) cfi tests are known to fail because they want the gold linker that we've removed from LFS.
  • PDF import is broken in libreoffice-25.2.1.2. If you need this feature, you can apply libreoffice-25.2.1.2-fix_pdfimport-1.patch before building the package.
