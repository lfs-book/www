Errata for BLFS systemd Version 12.2

  • In LLVM-19.1.7, if compiler-rt is built, many (more than a hundred) cfi tests are known to fail because they want the gold linker that we've removed from LFS.
  • PDF import is broken in libreoffice-25.2.1.2. If you need this feature, you can apply libreoffice-25.2.1.2-fix_pdfimport-1.patch before building the package.
  • The instructions for setting environment variables for the binary version of Texlive were insufficient. Please use the "Setting the PATH or TeX Live" page's instructions prior to using any Texlive applications for the first time.
  • The configuration file created for AppStream did not contain information for this release. When installing AppStream, use the version now provided in the development books.
  • The md5sum for libva as shipped was incorrect. The correct md5sum is 8dba13313d724b5e930f06e65b7437e2.
  • In libreoffice the option --with-help should be --with-help=html.

Known Security Vulnerabilities

Details of Security Advisories for this version of BLFS are now at Advisories for BLFS 12.3-systemd
