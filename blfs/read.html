BLFS Basic (beta)

A new book under development is Basic Packages for Linux From Scratch. This book is designed for new BLFS users and is an excerpt of the full BLFS book. It provides guidance for getting started with BLFS and suggests command line tools suitable for all types of systems. This short book provides merged instructions for users of both the System V and systemd versions of LFS.
