BLFS 6.2.0-rc1 release is coming soon!
Randy McMurchy - 2007/01/15

The BLFS team is ramping up for the next release of the BLFS book. There's just a few remaining bugs left to knock out and we'll be prepared to release a 6.2.0-rc1 version for community testing. This release is meant to supplement the LFS-6.2 version and includes many, many new features, packages and instructions. For the time being, if you're building on top of an LFS-6.2 platform, the development (SVN) version of BLFS is what you want to use. It is stable (though many packages could stand version updates) and recommended for all LFS-6.2 installations.
