BLFS 6.1 is released
Bruce Dubbs - 2005/08/20

The BLFS Editing Team is proud to announce that BLFS 6.1 has been released. This version complements the LFS 6.1 book and is available for download in pdf, single html page, and multiple html page formats. It is also available for on-line reading at the LFS Website.

BLFS 6.1-pre1 is now available for viewing at the LFS Website. Mirrors should synchronize within a day. This release is updates many BLFS packages and is the complement to the 6.1 version of LFS.
